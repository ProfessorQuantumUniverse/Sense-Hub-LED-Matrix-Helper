Ein kleiner Pixel-Editor: male dein 8×8-Muster auf der Oberfläche und erhalte den passenden Code für die LED-Matrix des Raspberry Pi Sense HAT.

## ✨ Features

- 🎨 Visueller 8×8-Pixel-Editor
- 🌈 Farbauswahl pro Pixel
- 📋 Generiert fertigen Code für die Sense-HAT-Matrix
- ⚡ Läuft komplett im Browser

## 🛠️ Tech-Stack

`HTML5` · `CSS3` · `JavaScript`
